## Inventory và cách đếm

Discovery đã chạy `rg -n "SelectField|Combobox|InlineSelect|<select|options=|formOptions|picker|purpose=" src/features src/app`. AST baseline tìm được **113 nhóm control trong 85 file, 211 select/radio/combobox controls**; nhóm render callback được tính riêng. Bổ sung **13 nhóm date/checkbox/file/color/action** mà select-only discovery không bắt được. Đây là audit toàn bộ nhóm control có dependency trong scope, không phải số route hay số field. Text-only forms không có lookup được kiểm tra cùng owner khi có trong nhóm. 11 nhóm preview component demo không thuộc picker dữ liệu connected.

Mỗi hàng bên dưới đã đối chiếu: field/dependency; API source; status/filter/effective date; clear/refetch khi parent thay; quyền; loading/error-retry/empty; Quick Create; invalidation; valid auto-select. API column ghi native repository owner (chuỗi gọi chi tiết ở source được liên kết), không lấy dashboard làm generic picker.

## Quy tắc chung đã đối chiếu

- Entity options dùng connected native API, không fallback demo. list helper paginate tới hết hoặc báo lỗi giới hạn; không cắt options âm thầm. Loading và API error không trở thành empty hợp lệ. QueryState/SchoolSourceState giữ read error + retry; PickerState dành cho options; raw notebook reads có loading/error/retry riêng.
- Mọi query private thuộc `staff-api` và authorization revision. Mutation được acknowledge mới refresh session rồi invalidate; mutation đến trong refetch tạo vòng refresh kế tiếp. Failed reads được retry sau mutation; cache parent/public giữ ownership riêng. Quick Create await refetch school-owned options trước callback.
- Auto-select chỉ ID có trong fresh native options và đúng filter/year/class/date. Entity tạo được nhưng chưa đủ điều kiện runtime có lời giải thích; backend vẫn kiểm tenant/quyền/status/year/date/conflict. Không hạ native write validation.
- Quick Create chỉ staff exact actions: year.manage, dictionary.manage, class.manage, member.create_direct **và** role.manage trên cùng grant, student.manage; guardian.manage + explicit guardian.verify; groups.manage; activity.manage. Class-scoped student action còn kiểm dated assignment. Parent/public/officer không thấy admin Quick Create.
- Modal/Drawer giữ parent mounted, chặn child submit bubbling, tăng overlay/content depth, ESC xử lý top layer, focus về opener; dirty close chỉ hỏi form đang đóng. Không dùng F5 để cập nhật options.
- Static enum filters không cần Quick Create. Published snapshot/parent/public controls không tạo thêm entity. Calendar năm học chỉ chọn tháng/học kỳ/tuần/ngày nghỉ; không có class dependency để chèn Quick Class.
